AtlasRead es una aplicación de escritorio diseñada para fomentar el hábito de la lectura, ofreciendo una experiencia interactiva y personalizada. Permite a los usuarios leer libros digitales, realiza un seguimiento de su progreso de lectura, ofrece recomendaciones basadas en la edad y evalúa la comprensión lectora mediante cuestionarios interactivos. Es una herramienta ideal para estudiantes y entusiastas de la lectura que buscan mejorar sus habilidades y registrar su trayectoria literaria.
Características Principales
Biblioteca de Libros Integrada: Almacena y gestiona una colección de libros en formato de texto plano (.txt).

Recomendaciones Personalizadas: Sugiere libros adecuados para el usuario basándose en su edad registrada.

Seguimiento de Sesiones de Lectura: Registra automáticamente la duración de las sesiones y calcula las palabras por minuto (WPM).

Cuestionarios de Comprensión: Incluye un sistema de quizzes al final de cada libro para evaluar la comprensión lectora del usuario.

Estadísticas de Progreso: Muestra estadísticas detalladas sobre el rendimiento de lectura, incluyendo puntuaciones de quizzes y promedio de WPM.

Gestión de Usuarios: Permite el registro de múltiples usuarios con sus edades para personalizar la experiencia.

Interfaz de Usuario Intuitiva: Desarrollada con CustomTkinter para una experiencia visual moderna y agradable.
Tecnologías Utilizadas
Python 3.x: El lenguaje de programación principal.

CustomTkinter: Biblioteca para la interfaz gráfica de usuario (GUI), ofreciendo widgets modernos y personalizables.

SQLite3: Base de datos ligera utilizada para almacenar información de usuarios, libros y sesiones de lectura.

python-dotenv: Para la gestión segura de variables de entorno (como rutas de archivos y configuraciones).

PyInstaller: Herramienta para empaquetar la aplicación en un ejecutable independiente para Windows (u otros sistemas operativos).
